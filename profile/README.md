# Bilup

**An open-source visual programming ecosystem built upon TurboWarp, designed for creators, educators, and developers.**

Bilup extends the Scratch experience with modern features while maintaining compatibility with the broader Scratch ecosystem.

Our goal is simple: make visual programming more powerful, collaborative, and accessible—especially for Chinese-speaking users.

---

## ✨ Why Bilup?

### 🔄 Broad Compatibility

Bilup supports projects from multiple ecosystems:

* Scratch
* TurboWarp
* MistWarp

Creators can work with existing projects while benefiting from Bilup's enhanced features and tools.

### 🤖 Bilup Nova

Bilup Nova brings AI capabilities into visual programming.

By using their own API keys, creators can integrate AI-powered workflows directly into their projects and development process.

### 👥 Real-Time Collaboration

Built upon collaborative technologies inspired by MistWarp, Bilup allows multiple users to work together on the same project.

Whether you're developing educational content, games, or community projects, collaboration becomes easier than ever.

### 🇨🇳 Designed for Chinese Creators

Bilup is developed with Chinese-speaking users in mind.

We strive to provide:

* High-quality Chinese localization
* Chinese-first documentation
* Community support
* Better accessibility for creators in China

### ⚡ Powered by TurboWarp

Bilup is built on the strong foundation of TurboWarp while introducing new capabilities and improvements tailored to our community.
